## How to run

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

This writes the diagnosis to `$MAKEFUN_OUTPUT_DIR/entry.txt`, validates the 1–200 character gate, reads the file back, and prints the path, byte count, and SHA-256. Standard library only; no network, no dependencies.
